Información que utiliza PerriWeb

PerriWeb utiliza el nick, los datos de acceso, el Perrilogo seleccionado y los disponibles, logros, títulos, karma, saldos, inventarios, progresos de los minijuegos, historial de operaciones y notificaciones para prestar sus funciones.

En el acceso tradicional se verifica una huella criptográfica de la contraseña; no se guarda su texto original. La aplicación utiliza identificadores de sesión y su fecha de caducidad para reconocer el acceso.

Acceso mediante Google

Si eliges Google, la autenticación se realiza mediante Google y Supabase Auth. Supabase Auth puede conservar el identificador de Google, el correo y los datos básicos de perfil facilitados por el proveedor. PerriWeb utiliza el identificador de Supabase Auth para vincular el acceso a tu nick. El nombre o la fotografía de Google no sustituyen automáticamente tu nick ni tu Perrilogo.

Los tokens recibidos durante el retorno se procesan en el servidor y no se entregan al navegador. PerriWeb no solicita acceso a Gmail, contactos o archivos de Drive para este inicio de sesión.

Información visible para otros usuarios

La lista de usuarios muestra nick, PC, Perrilogo y logros. Algunos minijuegos utilizan datos de otros jugadores para sus funciones, como los enfrentamientos. Las credenciales y los tokens de sesión no forman parte de esa lista pública.

Cookies y almacenamiento del navegador

La cookie de sesión permite mantener el acceso a PerriWeb. Para Google se utiliza además una cookie temporal que vincula el inicio y el retorno de la autenticación. La aplicación conserva temporalmente identificadores de operaciones en el almacenamiento de la pestaña para consultar su resultado si se interrumpe la conexión.

Seguridad y funcionamiento técnico

El servicio procesa los datos de conexión necesarios para recibir solicitudes, limitar intentos de acceso y diagnosticar fallos. Los diagnósticos de autenticación están diseñados para no registrar contraseñas, hashes ni tokens.
